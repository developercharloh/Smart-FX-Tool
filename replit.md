# Smart FX Tool

A smart forex trading analysis platform with SMC-based signal generation, live market news, economic calendar, and access key management.

## Run & Operate

- `pnpm --filter @workspace/trading-dashboard run dev` — trading dashboard frontend (port 24210, preview at `/`)
- `pnpm --filter @workspace/api-server run dev` — API server (port 8080, preview at `/api`)
- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from the OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)
- Required env: `DATABASE_URL` — Postgres connection string (auto-provisioned)

## Stack

- pnpm workspaces, Node.js 24, TypeScript 5.9
- Frontend: React + Vite + Tailwind CSS + shadcn/ui + Wouter + TanStack Query
- API: Express 5
- DB: PostgreSQL + Drizzle ORM (`signals`, `access_keys` tables)
- Validation: Zod (`zod/v4`), `drizzle-zod`
- API codegen: Orval (from OpenAPI spec)
- Build: esbuild (CJS bundle)

## Where things live

- `artifacts/trading-dashboard/` — React frontend (dark terminal aesthetic)
- `artifacts/api-server/src/routes/` — Express routes: signals, pairs, news, auth, admin, calendar
- `lib/db/src/schema/` — Drizzle schema (signals.ts, accessKeys.ts)
- `lib/api-spec/openapi.yaml` — OpenAPI spec (source of truth)
- `lib/api-client-react/src/generated/` — generated React Query hooks
- `lib/api-zod/src/generated/` — generated Zod validation schemas

## Architecture decisions

- Access gate: key-based (no user auth). Keys stored in `access_keys` table with plan/expiry. Frontend checks localStorage for `sfx_key`, verifies via POST /api/auth/verify.
- Admin panel lives at `/xk-manage` (hidden route, protected by `x-admin-secret` header sent from the client).
- Signal analysis uses simulated candles + in-process technical indicators (EMA, RSI, MACD, BB, ATR) — no external market data API needed.
- News fetched from RSS feeds (Reuters, MarketWatch, FXStreet, ForexLive) with 5-minute cache.
- Economic calendar fetched from ForexFactory JSON feed with fallback data.

## Gotchas

- After any OpenAPI spec change, run codegen before touching route or frontend code.
- The api-zod Zod schema names generated by Orval (e.g. `ListSignalsQueryParams`, `CreateSignalBody`) must match exactly what the routes import — grep `lib/api-zod/src/generated/api.ts` to confirm names.
- News and calendar endpoints are NOT in the OpenAPI spec — call them with plain fetch.
